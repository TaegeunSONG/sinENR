# SinENR — explicitly-parameterized neural representation with a sinusoidal basis

*This repository holds the code and the per-seed result tables. The manuscript
sources and the compiled documents are not part of the release, and the
rendered figures are not committed either, because the scripts here regenerate
them.*

SinENR is a single-hidden-layer perceptron with a sine activation,

```
y_hat(x) = b2 + sum_j  W2_j * sin( W1_j * x + b1_j )
```

in which each hidden unit *is* one sinusoidal component: after training, the
triplet `(W1_j, b1_j, W2_j)` is read directly as the frequency, phase and
amplitude of a component of the signal. No post-hoc attribution step is
involved — the weights are the spectral report.

The paper has two halves. The first fits this model and benchmarks the readout.
The second asks when the fitted parameters mean what they appear to mean, and
shows that on a uniform grid they are identifiable only modulo an alias group
generated by the sampling rate — a degeneracy that training loss, validation
loss, multi-start selection and early stopping are all blind to.

## What this revision changed

This version of the code accompanies a revision made in response to a referee
report. Two of the changes reversed earlier conclusions and are worth flagging
here rather than burying:

1. **Classical parametric estimators beat SinENR on the synthetic benchmarks.**
   Comparing against a zero-padded FFT alone was not sufficient. Given the true
   model order, nonlinear least squares, MUSIC, ESPRIT and the matrix pencil all
   recover continuous-valued frequencies, and on signals that are exact
   superpositions of a known number of tones they are more accurate than
   SinENR — by eleven orders of magnitude on the noiseless two-tone benchmark.
   The contribution of the paper is therefore not accuracy beyond the Fourier
   grid, which is classical, but the explicit parameterization and the
   identifiability analysis.
2. **The close frequency pair in the islet readout is not two physical modes.**
   Five independent checks (natural frequencies of the generating oscillators,
   an 8× longer trajectory, record-length sweep, penalty and model-order sweep,
   bootstrap) agree that the dominant cluster is one broad band represented by
   a few atoms whose individual positions are an artifact of record length and
   penalty. The claim that two modes were resolved below the Fourier limit has
   been withdrawn.

Terminology was corrected throughout: "resolution" → "estimation error" where
an estimation error is what is measured, and "Fourier limit" → "DFT grid
spacing 1/L".

## Reproducing the numbers

Requires Python 3.11+ and the packages in `requirements.txt` (`pip install -r
requirements.txt`). CPU is sufficient; every run below takes minutes, not hours.
The figure scripts write `fig*.pdf` and `fig*.png` into the repository root;
those outputs are not committed.

```bash
python benchmark.py             # tasks A/B/C -> results/results_raw.csv, results_summary.csv
python benchmark_extra.py       # contiguous-gap and lambda sweeps
python benchmark_baselines.py   # NLS / MUSIC / ESPRIT / matrix pencil on tasks A, B, C
python alias_analysis.py        # alias capture vs frequency prior bound
python islet_robustness.py      # the five close-pair checks (~3 min)

python make_figures.py                  # Figs. 1-3, 5, 7
python make_fig_missing.py              # Fig. 4 (refits; ~1 min)
python make_fig_islet_robustness.py     # Fig. 6
```

Every script routes its randomness through an explicit seed, so the reported
values reproduce exactly. The tables in `results/` are the ones behind every
number in the manuscript; nothing in the paper is computed outside this
repository.

## Two deliberate departures in the islet port

The Fortran uses Numerical-Recipes generators seeded from the system clock;
the Python port uses a seeded PCG64 generator so that a run is reproducible, and
optionally discards a burn-in interval. A trajectory from the port is therefore
statistically equivalent to, but not bit-identical with, one from the Fortran.
The equations, parameters, integrator and sampling interval are those of the
original. Both sources are included.
